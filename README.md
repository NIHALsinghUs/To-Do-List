# To-Do List

A simple command-line To-Do List application built with Python.

## Overview

This project allows users to manage their daily tasks through a menu-driven interface. Users can add multiple tasks, view existing tasks, and remove completed or unwanted tasks.

## Features

* Add tasks
* View all tasks
* Remove tasks
* Interactive menu system
* Basic input validation
* Beginner-friendly code structure

## Technologies Used

* Python 3

## What I Learned

Through this project, I practiced:

* Lists
* Loops
* Conditional statements
* Exception handling
* User input and output
* Program flow control

## How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program:

```bash
python todo_list.py
```
